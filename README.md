# 🐢 Python Turtle Noise

**Generating Random Noise with the Turtle Python Library**

## 🎨 Overview

This script leverages the `turtle` module to draw random lines and patterns, producing a noise-like visual effect. It's a fun way to explore randomness and graphics in Python.

## 🚀 Getting Started

### Prerequisites

* Python 3.x installed on your system.

### Installation

1. **Clone the repository:**

   ```bash
   git clone https://github.com/Aquatikss/Python-Turtle-Noise.git
   cd Python-Turtle-Noise
   ```

2. **Run the script:**

   ```bash
   python main.py
   ```

   A window will pop up displaying the generated noise pattern.
